# ProjectOps

ProjectOps is a lightweight IT project management application built with **Python, Streamlit, and SQLite**.

## Features

* Project management
* Project-specific workspace
* Requirements management
* Task management
* Change requests
* Issue tracking
* Project notes

## Tech Stack

* Python
* Streamlit
* SQLite
* Git & GitHub

## Run Locally

```powershell
.\.venv\Scripts\Activate.ps1
python -m streamlit run app\main.py --server.port 8510
```

Open:

```text
http://localhost:8510
```
